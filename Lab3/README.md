#### Задача по варианту (11 вариант)

### формулы
Для $f: \mathbb{R}^n &rarr; \mathbb{R}^m$, то есть $f(x) = y$, где $x \in \mathbb{R}^n$, $y \in \mathbb{R}^m$ 
матрица Якоби 
```math
J_h = \begin{pmatrix} 
\dfrac{\partial y_1}{\partial x_1} & \dfrac{\partial y_1}{\partial x_2} & \dots & \dfrac{\partial y_1}{\partial x_n} \\
\dfrac{\partial y_2}{\partial x_1} & \dfrac{\partial y_2}{\partial x_2} & \dots & \dfrac{\partial y_2}{\partial x_n} \\ 
\vdots & \vdots & \ddots & \vdots \\
\dfrac{\partial y_m}{\partial x_1} & \dfrac{\partial y_m}{\partial x_2} & \dots & \dfrac{\partial y_m}{\partial x_n} 
\end{pmatrix}
```

Градиент – частный случай матрицы Якоби (транспонированной) – первая строка матрицы Якоби  
для функции $f: \mathbb{R}^n &rarr; \mathbb{R}$, то есть $f(x) = y$, где $x \in \mathbb{R}^n$, $y \in \mathbb{R}$ 
градиент
```math
\nabla f = \begin{pmatrix} 
\dfrac{\partial y}{\partial x_1} \\ 
\dfrac{\partial y}{\partial x_2} \\ 
\dots \\ 
\dfrac{\partial y}{\partial x_n}  
\end{pmatrix}
```

Функция Лагранжа $L(x, \lambda) = f(x) + \sum\limits_{i=1}^m \lambda_i h_i(x)$, 
где $\lambda \in \mathbb{R}^m$ – множители Лагранжа (неопределенные коэффициенты), 
$x \in \mathbb{R}^n$

### Ход работы
#### 1. Анализ задачи
[► перейти к заданию ◄](#1-анализ-задачи)

Целевая функция $f(x, y) = x + y$

Переменные $(x, y) \in R^2$

Ограничения: $h(x, y) = x^2 + 4y^2 - 4 = 0$

Области определения $D(f) = D(h) = \mathbb{R}^2$

Дифференцируемость функций: $f, h \in C^\infty(\mathbb{R}^2)$

Допустимое множество $D = \{(x, y) \in \mathbb{R}^2 \mid x^2 + 4y^2 = 4\}$ является 
каноническим эллипсом с полуосями $a = 2$ и $b = 1$. $D \neq \varnothing$, так как:
- [x] $(\pm 2, 0) \in D$
- [x] $(0, \pm 1) \in D$

Градиент ограничения $\nabla h(x, y) = \begin{pmatrix} \dfrac{\partial h}{\partial x} \\ \dfrac{\partial h}{\partial y} \end{pmatrix} = \begin{pmatrix} 2x \\ 8y \end{pmatrix}$

Матрица Якоби $J_h = \begin{pmatrix} 2x & 8y \end{pmatrix}$ состоит из одной строки, так как у нас всего одно ограничение.

$\text{rk}(J_h) < 1 \iff \nabla h(x, y) = (0, 0)^T \iff x = 0 \text{ и } y = 0$
Точка $(0, 0)$ не лежит на эллипсе: $0^2 + 4(0)^2 = 0 \neq 4$, следовательно, 
во всех точках допустимого множества $D$ градиент $\nabla h(x, y) \neq (0, 0)$, 
ранг матрицы Якоби равен $m = 1$ (полный ранг). 
То есть условие регулярности выполняется.

Множество $D$ является замкнутым (задано непрерывным уравнением) и ограниченным ($|x| \le 2$, $|y| \le 1$), 
то есть компактом в $\mathbb{R}^2$.
Целевая функция $f(x, y)$ непрерывна на $D$. 
По теореме Вейерштрасса непрерывная функция на компактном множестве 
достигает своего глобального максимума и глобального минимума.

**Поскольку функции гладкие, допустимое множество непусто и компактно, 
а градиент ограничения линейно независим во всех допустимых точках, необходимое условие экстремума Лагранжа применимо. 
Глобальные экстремумы гарантированно существуют и находятся среди стационарных точек функции Лагранжа.**

#### 2. Ручное решение
[► перейти к заданию ◄](#2-ручное-решение)

Функция Лагранжа $L(x, y, \lambda) = f(x, y) + \lambda \cdot h(x, y) = x + y + \lambda (x^2 + 4y^2 - 4)$
```math
\begin{cases}
\dfrac{\partial L}{\partial x} = 1 + 2\lambda x = 0 \\
\dfrac{\partial L}{\partial y} = 1 + 8\lambda y = 0 \\
h = x^2 + 4y^2 - 4 = 0
\end{cases} 
= 
\begin{cases}
1 + 2\lambda x = 0 \\
1 + 8\lambda y = 0 \\
x^2 + 4y^2 = 4 
\end{cases}
```

Из первых двух уравнений выразим переменные через $\lambda$ (заметим, что $\lambda \neq 0$):
$$x = -\frac{1}{2\lambda}$$
$$y = -\frac{1}{8\lambda}$$

Подставим выражения для $x$ и $y$ в уравнение $x^2 + 4y^2 = 4$:
$$\left(-\frac{1}{2\lambda}\right)^2 + 4\left(-\frac{1}{8\lambda}\right)^2 = 4$$
$$\frac{1}{4\lambda^2} + 4\cdot\frac{1}{64\lambda^2} = 4$$
$$\frac{1}{4\lambda^2} + \frac{1}{16\lambda^2} = 4$$
$$\frac{4 + 1}{16\lambda^2} = 4 \implies \frac{5}{16\lambda^2} = 4 \implies \lambda^2 = \frac{5}{64}$$
$$\lambda = \pm \frac{\sqrt{5}}{8}$$

**Случай 1:** $\lambda_1 = -\dfrac{\sqrt{5}}{8} \approx -0.2795$
$$x_1 = -\frac{1}{2(-\sqrt{5}/8)} = \frac{4}{\sqrt{5}} = \frac{4\sqrt{5}}{5}$$
$$y_1 = -\frac{1}{8(-\sqrt{5}/8)} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$$
Точка $P_1 = (\frac{4\sqrt{5}}{5}, \frac{\sqrt{5}}{5}) \approx (1.7889, 0.4472)$
$$h(P_1) = x_1^2 + 4y_1^2 = \left(\frac{4}{\sqrt{5}}\right)^2 + 4\left(\frac{1}{\sqrt{5}}\right)^2 = \frac{16}{5} + \frac{4}{5} = \frac{20}{5} = 4 \quad (\text{верно})$$
$$f(P_1) = \frac{4\sqrt{5}}{5} + \frac{\sqrt{5}}{5} = \frac{5\sqrt{5}}{5} = \sqrt{5} \approx 2.2361$$


**Случай 2:** $\lambda_2 = \dfrac{\sqrt{5}}{8} \approx 0.2795$
$$x_2 = -\frac{1}{2(\sqrt{5}/8)} = -\frac{4}{\sqrt{5}} = -\frac{4\sqrt{5}}{5}$$
$$y_2 = -\frac{1}{8(\sqrt{5}/8)} = -\frac{1}{\sqrt{5}} = -\frac{\sqrt{5}}{5}$$
Точка $P_2 = (-\frac{4\sqrt{5}}{5}, -\frac{\sqrt{5}}{5}) \approx (-1.7889, -0.4472)$
$$h(P_2) = x_2^2 + 4y_2^2 = \left(-\frac{4}{\sqrt{5}}\right)^2 + 4\left(-\frac{1}{\sqrt{5}}\right)^2 = \frac{16}{5} + \frac{4}{5} = 4 \quad (\text{верно})$$
$$f(P_2) = -\frac{4\sqrt{5}}{5} - \frac{\sqrt{5}}{5} = -\sqrt{5} \approx -2.2361$$

Так как глобальные экстремумы на компакте $D$ гарантированно существуют (по теореме Вейерштрасса), а метод Лагранжа выявил лишь две критические точки:
1. $P_1\left(\dfrac{4\sqrt{5}}{5}, \dfrac{\sqrt{5}}{5}\right)$ – точка глобального максимума, $f_{\max} = \sqrt{5}$.
2. $P_2\left(-\dfrac{4\sqrt{5}}{5}, -\dfrac{\sqrt{5}}{5}\right)$ – точка глобального минимума, $f_{\min} = -\sqrt{5}$.
