### Поиск центра уголка по двум точкам: левой $(x_l, y_l)$ и правой $(x_r, y_r)$ (вывод формул для функции `find_corner()` класса `FindMinProblem`)
Ищем пересечение двух функций $g_l(x)$ и $g_r(x)$. 
Функция $g_l(x)$ проходит через левую точку $(x_l, y_l)$,
функция $g_r(x)$ - через правую $(x_r, y_r)$

$$g_l(x) = -kx + c_l$$
$$c_l = kx_l + y_l$$
$$g_l(x) = -kx + kx_l + y_l$$

$$g_r(x) = kx + c_r$$
$$c_r = -kx_r + y_r$$
$$g_r(x) = kx - kx_r + y_r$$

$$-kx + kx_l + y_l = kx - kx_r + y_r$$
$$2kx = kx_l + y_l + kx_r - y_r$$

Итоговые формулы для нахождения координат центра уголка:
$$x = \dfrac{1}{2}(x_l + x_r + \dfrac{y_l - y_r}{k})$$
$$y = \dfrac{1}{2}(kx_l + kx_r + y_l - y_r) - kx_r + y_r = \dfrac{1}{2}(kx_l - kx_r + y_l + y_r)$$
