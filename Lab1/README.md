## Лабораторная работа №1 по теме `Симплекс метод`
### Задание
Решить задачу двумя способами: вручную и при помощи надстройки Excel "Solver" – и сравнить ответы.

Задача – максимизировать функцию $z = x_1 + 2 x_2 + 4 x_3 + x_4$ при условиях:

$$
\begin{cases}
x_1 + x_2 + x_3 \le 10 \\
x_2 + 2 x_3 + x_4 = 6 \\
x_1 + x_4 \ge 2 \\
\forall i \in \mathbb{N} \rightarrow x_i \ge 0
\end{cases}
$$

в файле [Solver.xlsx](Solver.xlsx) – решение задачи в Excel, в файле [Program.py](Program.py) – решение задачи в Python. 
Ответы, полученные разными способами решения, совпали.
